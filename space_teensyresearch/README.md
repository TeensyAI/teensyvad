# TeensyVAD: Tiny Voice Activity Detectors for Telephony

Paper page for **TeensyVAD by VoxLogic** (families v1–v4):
20k–100k-parameter voice activity detectors, pure NumPy, 8 kHz telephony
native, distilled from Silero VAD and trained up to the full 100 h of
LibriSpeech train-clean-100.

Contact: [pankaj@voxlogic.ai](mailto:pankaj@voxlogic.ai)

Highlights: TEN VAD public-set AUC 0.880 (FlashVAD publishes 0.882 with
2.3× the parameters), AMI real-room frame F1 0.886 vs Silero's stock
0.714, and a 28 KB int8 QAT model that beats its 87 KB float32 parent.
